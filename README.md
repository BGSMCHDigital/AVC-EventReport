# AVC EVENTREPORT (front-end build)

Open `index.html` in a browser, or deploy the folder to Vercel/Netlify as a static site.
The page's responsive monochrome styling and visual effects are maintained in the linked `styles.css` file.

Local mode only: data is stored in the browser, article drafting is rule-based (no AI), and admin sign-in is not secure.
The admin's “Mark Published” action records a local status only; it does not upload or publish content to an external website. “Print / PDF” opens a print-ready report with event details, the generated article, and submitted photos; choose “Save as PDF” in the browser's print dialog to export it.

Supabase auth, database, storage, AI Edge Function, user invites and CMS integration are not included.
